# 调酒资料本地库

- 采集日期：2026-11-12（北京时间）。
- 数据文件：`app/src/data/cocktail-social-library.json`，随前端构建打包，首次打开无需联网下载。
- 60 条独立原帖：Bilibili 41 条、抖音 19 条。小红书公开搜索未获得可用原帖，不以其他平台转载代替。
- 检索范围：便利店调酒、果立方、水溶C、养乐多、茉莉茶、百利甜、椰奶、柠檬茶、橙汁及家庭调酒。通过公开网络搜索获取，限定原帖路径并排除商品广告、游戏攻略及无关饮品。
- 按平台和视频编号去重；抖音精选与主站同编号合并，去除跟踪参数。
- `verification: search-index` 表示搜索索引可见，未声明已播放视频、核验作者或验证每个原帖当前可访问。
- `recipeStatus: partial` 共 12 条，摘要包含检索可见的部分材料或用量；缺失的量、杯容量、顺序未补写。其余为 `link-only`。
- 本批只存标题、简短整理摘要、标签、来源链接和采集日期；未下载视频或原帖照片。内置基础配方的照片仍为独立资源。

## 页面行为

本地库优先显示，与已有 localStorage 搜索缓存合并，不覆盖本地整理摘要。支持本地关键词检索、平台筛选、每批 18 条与 JSON 导出。联网失败不影响本地内容。

现有桌面端自动搜索仍通过公开搜索索引完成，三平台覆盖不稳定；新采集的此批资料不依赖该接口。数据日期是采集日期，不是视频发布日期。

## 验证

校验 60 个视频编号和链接唯一、来源主机符合平台、必需字段完整；执行前端 TypeScript 检查及 Vite 生产构建。

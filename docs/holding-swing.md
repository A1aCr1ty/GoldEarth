# 持仓波段操作

股票账户新增「波段操作」，与持仓概览、买卖流水并列，原交易计划与AI复盘入口不恢复。只请求当前账户数量>0的持仓，单次最多50只，按证券代码去重；账户内保存机动仓设置和计划快照，切换账户隔离。

进入页面、手动同步、成功模型复盘事件及页面打开期间跨日会重新计算。使用与股票策略相同的冻结模型；按每只持仓的历史日线计算2024年后的收益、最大回撤、已平仓交易数和交易胜率，并生成5/20交易日预测。当前模型逐股回溯不等于用户真实做T或机动仓收益，也不代表新融合模型已经通过验证。

机动仓默认0，需自行填写股数，底仓=导入持仓−机动仓。计划只给出回调、冲高、卖出后接回、突破不回调及停止波段条件；可卖上限取用户机动仓、导入持仓和可用数量的最小值并向下取整手。可用量未知、历史过期、数量无效或不足一手时暂停触发。基本面缺失或模型未通过验证时不放行新增买入。卖出后接回要求先核实真实成交并重新导入流水，不能把建议或保存动作当成交。

MA5、MA20、黄线、20日高低及ATR均为前复权观察指标，不直接映射为未复权委托价格。持仓数量和可用量来自最近导入，市场报价不能证明新成交已同步。计划保存的是当时持仓、机动仓及研究报告的快照，新的实时计划随重新复盘更新。

预测账本位于应用数据目录 `strategy/platform/swing_prediction_ledger.json`，与原研究样本账本独立。每只股票/信号日期/周期仅保留首次发布概率。到期标签采用下个交易日开盘到horizon个开盘间隔后的收益，全部实现后才评分。按股票和周期分别统计方向正确率（概率>=50%为上涨，实际收益>0为上涨）、原始/修正Brier误差，且每项显示已到期数量。0样本显示待积累，不能显示0%或100%。每日预测区间可能重叠，不视为独立样本。

概率偏差校准只使用同股票同周期、预测日之前已经结算的最近100条；至少20条后才修正，修正幅度不超过±10个百分点。修正可能降低准确率，界面保留原始对照。历史走步准确率、实发预测正确率与交易胜率分栏展示，不能互相替代。

验证：Python执行与前视/账本测试、前端机动仓/可卖量/过期/风险优先测试、Tauri命令ACL构建检查。真实行情烟测以两只原研究标的验证，未读取或修改用户账户实际持仓。

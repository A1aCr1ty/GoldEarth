# 盈利效果评估方案 v1 — 2026-11-08预先登记

目的：衡量A股3—12个月研究模型能否在承担可接受风险的前提下，长期覆盖交易、数据及AI费用。每月盈利不是可保证的条件。以下方案在本轮计算前确定；修改参数必须产生新实验，不覆写失败实验。

## 评价与账本

1. 预测：按月横截面Rank IC、排名分组收益、相对旧线性模型的改善；排序分数不是上涨概率或收益率。
2. 组合：每日权益、累计净利润、年化收益、最大回撤、月度收益、最长连续亏损月、交易次数、交易费用与换手；同时对照沪深300价格指数、相同股票池简单动量与低波动策略。
3. 费用覆盖：逐月先扣交易费用，再扣AI及数据费；报告盈利月份占比、费用覆盖月份占比、年度净利润和连续不能覆盖费用的月份。不能拿总收益除以月份替代逐月检验。
4. 资金敏感性：实际本金/费用未知时使用明确的假设；默认研究情景10万元本金、AI每月300元、数据费0元、最大回撤20%。另外计算1万/5万/10万本金与100/300/1000元月费的情景，固定费用与最低佣金需逐账户重新计算。

## 本轮固定候选，不按结果扩张网格

- 原始技术特征的岭回归（正则100）。
- 横截面特征与未来超额收益排名的岭回归（正则100）。
- 相同排序目标的直方图梯度提升树（80轮、15叶、最小叶样本100、L2=10、学习率0.05、固定种子；禁用随机内部early stopping）。
- 简单基线：126日动量、63日低波动、沪深300价格指数；不把最优参数网格当成基线。
- 周度训练样本；月末出信号，下一市场交易日开盘执行。预测期63/126/252交易日，本轮首先固定126日。
- 每年重新训练：只用训练截止日前已成熟标签，最多近6年样本。2020—2023为开发比较期，2024以后为已触及的研究复核期。后者不能恢复成独立测试集。
- 只按开发期扣费后的风险调整收益挑选候选，复核期不反向改参数。所有候选和简单基线都保留，不只报告赢家。
- 每月持有目标30只；上期持股仍处于前60名时保留，再补足30只，等权再平衡。预测期6个月并不意味着所有股票固定持有6个月，实际持仓变化由账本记录。

## 成本和交易假设

默认佣金情景为双边万3、每笔最低5元，按包含交易规费的综合佣金假设处理，避免重复计费；用户应以实际券商交割单替换。卖方印花税按历史日期：2023-08-28前0.1%，之后0.05%。滑点分别测单边10/20/50基点。数据费默认为0仅表示未知假设，不表示所有数据免费。

- [上交所当前收费表](https://www.sse.com.cn/services/tradingservice/charge/ssecharge/)
- [税务机关：2023-08-28起印花税减半](https://shanghai.chinatax.gov.cn/gate/big5/shanghai.chinatax.gov.cn/zcfw/zcfgk/yhs/202308/t468451.html)

当前只有复权日线，第一轮组合回测属于研究模拟：用复权份额而非真实整手股数；无报价不成交，估值沿用最近报价并单独记录陈旧估值；开盘与前收盘相差超过4.8%时保守拒绝交易（不是准确的涨跌停判定）。不使用当日收盘、最高最低或全天成交量判断开盘成交。记录费用、现金、持股、未成交原因；不得借用未来报价。AI费用从现金扣除，不足时尝试减持筹资，无法支付的部分记为负债，权益扣除，不隐瞒破产。

完整历史ST/退市/板块规则、原始不复权价格、分红送转及可成交量尚未齐全，因此不论模拟收益如何，自动实盘准入保持关闭。

## 准入门槛（研究门槛，不承诺收益）

- 开发期扣费后收益为正、最大回撤不超过配置值，不能仅靠单一年份盈利。
- 复核期需至少24个完整月份；净收益为正、超过相同股票池简单基线，双倍滑点仍不亏损。
- 费用覆盖月份占比至少60%，年净利润至少为年AI与数据费的两倍。该条件只筛选，不代表未来可持续。
- 按月份做连续区块bootstrap（区块6个月，固定种子，500次）报告平均月收益的区间；重叠预测样本不视为独立观测。既有多次试验会使区间乐观，因此只作描述，不给显著性保证。
- 完成真实可交易数据审计、至少6个月前瞻模拟；12个月才可初步评价年度费用目标，且不因历史门槛通过自动下单。

多重试验依据：[Bailey / López de Prado，Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)。本轮保存候选数和全部试验，不冒称已经计算DSR/PBO。

## 数据扩大

### 第二轮风险控制实验（首轮失败后追加登记）

首轮三个模型均未通过开发期20%回撤门槛。为检验风险控制而不是继续扩大预测参数网格，新增且只新增同一仓位规则：月末沪深300收盘低于MA200时目标风险仓位25%；否则采用12%年波动目标/过去63日年化波动，限制在20%至80%之间。规则只读取信号日已知行情，次日开盘实施，每月重平衡，剩余资金按零利息现金处理。

该规则同时用于三个模型，保留无仓位控制的三个版本和三个简单基线，总计六个模型版本与三个基线。开发期仍是唯一选择依据；原先已查看的复核期仍仅是研究诊断，不能据此证明独立提升。不因加入规则把试验计数清零。

## 数据扩大明细

- 财报由505家公司扩到现有全量行情股票，保留原始版本与失败清单；未核验历史披露版本仍不进入历史训练。
- 周度取样扩大训练观察数量，但共享未来持有期并不增加等量独立信息；严格以标签结束日隔离训练和预测。

- 对比行情指纹；发生数据、代码、配置变化时新建版本。未来真正未使用的区间从实验冻结后开始记录。

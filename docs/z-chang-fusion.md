## 分工与操作顺序

1. 常士杉层先回答“环境允许冒多大风险、公司和价格是否值得研究”。看全球流动性/利率、沪深市场趋势、行业景气、营收、毛利率、现金流、利润与估值。当前只有沪深300价格代理和财报输入接口，全球宏观及行业历史数据未接齐。
2. 环境偏弱时暂停新增风险，先复核原止损与弱势仓位；环境过渡时等待；环境偏强且财务与估值审核通过，才进入Z哥买点审核。
3. Z哥层回答“何时进入/退出”：双线先判趋势，KDJ看回调，量能确认B1/B2，MACD作强弱过滤。技术满足仍只是候选，最后核对真实报价、账户风险预算、可用资金和T+1可卖数量。
4. 卖出与风险纪律优先于新增买入；基本面缺失不能以技术强势替代。现阶段组合未经历史时点财报回测，因此账户正式动作仍为观望，显示风险复核提示，不自动下单。

## 明确指标和研究规则

|层次|具体定义|操作解释|
|---|---|---|
|市场状态|沪深300收盘、MA20、MA60、RSI14；收盘>MA60且MA20>MA60为偏强，二者反向为偏弱，其余过渡|这是可复现的工程代理，不宣称为常士杉原版预测|
|大盘概率|沿用工程KNN按已实现标签预测下个开盘开始5/20个开盘间隔收益；滚动验证不过则方向中性|概率是模型输出，不是作者观点；不因单次预测解除组合验证限制|
|财报质量|营收同比≥20%、毛利率变化≥0、经营现金流>0、净利润>0、ROE≥15%|营收20%表示高成长筛选；毛利率持平是否放行是工程口径，不能涵盖所有价值股|
|估值|估值分位≤70%|必须使用当时可知的历史/行业估值口径；70%是保守研究阈值，不是作者统一标准|
|白线|EMA(EMA(C,10),10)|短期趋势|
|黄线|(MA14+MA28+MA57+MA114)/4|多空趋势；区别于旧模型的3/6/12/24 BBI|
|KDJ|9,3,3递推，初值K=D=50；J=3K−2D|当前B1采用该仓库J<30；B2前5日曾J≤−10且当前J<55，阈值为版本选择|
|MACD|DIF=EMA12−EMA26|B1要求DIF>0|
|B1候选|白线>黄线、黄线不下降、J<30、当日量<近20日最大量×0.618、DIF>0、60日内未翻倍|另用“近20日低点高于此前40日低点且前段至少涨10%”近似N形；不称完整碗口识别|
|B2候选|双线多头、近5日J超卖、当天涨幅≥4%、量≥此前5日均量1.5倍、当前J<55|部分仓库还要求上影、完整B1序列及建仓质量，当前尚未完整实现|
|退出观察|跌破黄线；或前阳后阴且阴量≥前阳量3/4|只作日线风险提示，不能保证触发价成交；关键K低点为前复权研究价，不能直接作未复权委托价|

完整Z哥市值≥40亿、换手率及建仓波、完整N型、S1和主线龙头识别缺数据或专门识别器，输出中明确标记缺失，当前只称部分技术研究实现。资料中的“三低”也不简化为低股价自动买入。

## 财报数据契约

应用数据目录 `strategy/data/fundamentals.json` 可放记录数组。必须有证券代码、公告日期和可核查来源；仅使用公告日期不晚于信号日的最新记录，180日以上待复核。字段：

```json
[
  {
    "code": "示例代码，替换为真实6位代码",
    "published_on": "2026-10-30",
    "source": "真实公告或数据来源URL",
    "revenue_growth": 0.25,
    "gross_margin_change": 0.01,
    "operating_cashflow": 100000000,
    "net_profit": 80000000,
    "roe": 0.16,
    "valuation_percentile": 0.5
  }
]
```

增长、ROE、分位均用0—1比例；毛利率变化用百分点对应的小数（提高1个百分点为0.01）；现金流/利润用同一货币单位。估值分位的计算应由来源明确。示例纯说明，不写入真实数据。缺值、未来公告或过期数据返回unknown，不伪造财报。尚无可核实财报时覆盖数为0，这是当前实际状态。

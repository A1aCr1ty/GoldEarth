# A股长期投资研究

目标：研究未来63、126、252个交易日（约3、6、12个月）的投资价值，并最终评估扣除交易成本、数据与AI费用后的收益。当前是研究原型，不是已验证的自动投资系统。

## 已实现

- 股票看板新增「长期研究」；支持500/1500/全沪深当前股票池等采集规模、补充财报、技术基线和融合模式、ONNX导出和本地推理、按实验版本保存结果。
- 日线复用现有数据接口，目标起点2015年，实际覆盖取决于接口。技术特征包含MACD、KDJ、均线偏离、成交量比、动量、波动和回撤。
- 财报请求最近200条，保留原始响应、报告期、公告日、采集时间、来源及后续版本。财务比率的百分数归一成小数。新下载记录不回填历史。
- 以沪深300的共同月末交易日取样；停牌股票不会用月内最后一次报价冒充月末。信号后下一交易记录开盘买入假设；目标为持有期收益减同期基准收益。
- 按时间分割并剔除跨边界标签；只在训练集拟合标准化参数，验证集从3个岭回归正则参数中选取。测试集只报告结果，不用于自动选择模型。
- ONNX保存标准化、系数和截距；实际ONNX Runtime执行预测，并与NumPy实现比较。只有导出和核验成功才发布最新候选结果，旧版本不覆盖。
- 页面显示验证基线是否通过。所有结果仍为研究候选，无真实下单或自动上线。
- 费用覆盖输入：本金、每月AI费、可接受回撤。年度AI费用/本金仅为费用门槛；回撤目标尚未接入交易风控。
- 财报页新增六部分机构研究清单，显示已有财报依据和待补资料；Agent新增「长期价值研究」预设与带来源的方法上下文。

## 实测（2026-11-08）

已有4966个CSV，其中4962个证券候选（排除两个股票池清单和两个已知指数）。6个月技术基线使用4812只股票、421182个月度样本。首次实验发现个股停牌导致非统一月末分组，修复为共同市场日历后重跑，旧实验只留作审计。

| 零超额预测基线误差 | 18.55个百分点 | 24.55个百分点 |
| 月度横截面Rank IC均值 | -0.1110 | 0.0320 |

**验证未通过：不能据此声称可盈利或覆盖AI费用。** ONNX最大误差约4.46e-8。前20%持有期超额均值不能叠加为组合收益，持有窗口重叠且存在幸存者偏差。

初次采集500只股票全部成功，加上5家接口核验样本，共505家公司、31767条财务指标记录。随后扩展到当前行情池全部4962只股票；`000881`首次请求超时，补采成功，最终失败清单为空。这些快照不等同于历史原始公告，也不等同于已具备历史时点版本，未用于本轮历史训练。

### 周度样本与组合复核

最终实验为 `evaluation-20261108T053601-8252b5f3`：4784只有效股票、2127036条周度观察，其中1960416条标签已成熟。所有模型使用相同交易账本；研究情景为10万元本金、每月300元服务费、单边10基点滑点。结果如下（净利润为整个区间累计值，不是年化收益）：

| 模型 | 开发期净利润 | 开发期最大回撤 | 复核期净利润 | 复核期最大回撤 | 复核期费用覆盖月份 |
|---|---:|---:|---:|---:|---:|
| 原始岭回归 | 72529元 | 44.67% | 80234元 | 34.34% | 48.48% |
| 排序岭回归 | 68634元 | 21.32% | 7645元 | 24.57% | 51.52% |
| 非线性排序树 | 49359元 | 29.86% | 77103元 | 19.86% | 69.70% |
| 原始岭回归＋仓位控制 | 31032元 | 26.88% | 7278元 | 27.52% | 48.48% |
| **排序岭回归＋仓位控制（开发期选定）** | **5713元** | **14.58%** | **-12915元** | **16.60%** | **45.45%** |
| 非线性排序树＋仓位控制 | 7191元 | 20.65% | 13200元 | 13.30% | 66.67% |

仓位控制降低了所选模型的回撤，但复核期净收益、相对简单基线、双倍滑点和费用覆盖门槛均未通过。没有因为其他模型在复核期盈利就更换候选；复核期已受多轮研究影响，不能再称为独立测试。逐月权益、交易明细、压力测试和资金情景均保存在该实验目录，候选ONNX与原始实现最大输出误差约2.24e-8。

## 运行

开发模式训练：`src-tauri/.taurignore` 排除研究缓存、模型及公告语料，避免每次落盘触发应用重启。已运行的旧Tauri监听器只在启动时读取规则，需在原启动终端按Ctrl+C后重新启动一次。项目根目录 `npm run dev:stable` 可运行不自动重启Rust进程的模式；前端仍保留开发服务器。

命令行评估支持 `--output-root D:/GoldEarth/.runlogs/value-experiments`，读取原有行情但把进度、实验和模型写到监听范围之外。通过 `python -B` 运行可避免源码目录生成Python字节码。应用内训练本来使用app-data目录，与源码实验目录分开。

源码实验的独立Python环境位于 `.runlogs/value-venv`，已安装依赖。运行示例（项目根目录）：

```powershell
.\.runlogs\value-venv\Scripts\python.exe -m unittest discover -s src-tauri/resources/strategy -p test_value_lab.py -v
.\.runlogs\value-venv\Scripts\python.exe src-tauri/resources/strategy/value_lab.py financials --limit 500
.\.runlogs\value-venv\Scripts\python.exe src-tauri/resources/strategy/value_lab.py train --horizon 126 --mode technical
```

源码实验输出在 `src-tauri/resources/strategy/value/`（Git忽略）；模型位于 `runs/<实验ID>/model.onnx`，同目录 `result.json` 保存特征顺序、数据/代码SHA256、参数、区间指标、逐股预测和失败原因。使用ONNX时必须保持特征顺序，缺失值不得随意填零。

桌面应用使用自己的 app-data/strategy 数据目录，独立于源码实验目录，界面展示实际路径。设置进程环境变量 `GOLDEARTH_PYTHON` 指向具备依赖的解释器后启动新版应用。新安装环境按 `value_requirements.txt` 安装依赖。界面采集限速、保存逐项进度和失败原因；与已有策略更新共用互斥，避免同时改行情缓存。重复补充财报会复用当天快照。

## 原文、研报与论文语料

`value_corpus.py` 新增两条可恢复采集链：

- 巨潮资讯官方接口按当前行情池采集年报、半年报、一季报和三季报，剔除摘要、英文版、提示和问询回复；保留修订版、公告日期、原始PDF、SHA256、逐页文本及1200字分块。公告时间戳按中国时区转换。
- `knowledge_sources.json` 登记公开论文、机构方法资料和可访问研报。网页与PDF只保存公开响应，403、证书错误、登录或付费要求会记入失败清单，不绕过限制。目录文字不等于研报全文。

```powershell
.\.runlogs\value-venv\Scripts\python.exe src-tauri/resources/strategy/value_corpus.py filings
.\.runlogs\value-venv\Scripts\python.exe src-tauri/resources/strategy/value_corpus.py knowledge
.\.runlogs\value-venv\Scripts\python.exe src-tauri/resources/strategy/value_corpus.py status
```

输出位于 `value/corpus/`；`filings/` 是逐公司索引，`originals/` 是原文，`text/` 是逐页文本与分块，`filing_progress.json` 和 `knowledge_progress.json` 保存进度。首次真实核验已取得平安银行108份定期报告并解析首份PDF；全量任务需要较长时间，完成数以状态文件为准。

**语料完成采集不等于已训练。** 研报和论文用于分析框架、特征假设和检索引用，不把评级或目标价当收益标签。财报原文必须按披露日和版本生效，文本特征只能在训练区间拟合，再经过新的滚动样本外与扣费组合验证；当前 `training_admitted=false`，尚未把文本加入收益模型或宣称效果提升。扫描件需OCR，无法提取文本的文件保留失败原因。

## 历史财报导入契约

融合模式读取 `value/financials/<六位代码>.json` 数组。每条至少含：

```json
{
  "code": "600000",
  "report_date": "2020-12-31",
  "published_on": "2021-03-31",
  "available_on": "2021-03-31",
  "observed_at": "2026-11-08T00:00:00+00:00",
  "source": "原始公告链接",
  "vintage_verified": true,
  "vintage_evidence": "原始公告文件路径、页码及内容SHA256；人工或解析核验记录",
  "roe": 0.10,
  "revenue_growth": 0.05,
  "profit_growth": 0.04,
  "gross_margin": 0.20,
  "debt_ratio": 0.40,
  "cash_profit": 1.1
}
```

仅声明 `vintage_verified` 而没有证据字段不会启用历史回填。程序无法替用户证明证据真实性，需对原始文件做核验；修订版使用修订披露日，不能覆写原版。公告当日不生效，保守采用下一可用交易日。金融行业通用指标不完整时不会强行填充，应另建行业专用模型。

## 机构资料核验

详见 `app/src/lib/institutionalResearch.ts`。核验截至2026-11-08：

- 中信证券：官方公开摘要与入口，未取得全部个股研报全文。
- 中金公司：官方研究平台介绍，不是具体股票观点。
- 华泰证券：公开信用研究方法介绍；借鉴分层研究，不将信用模型冒充股票策略。
- 招商国际：公开公司/行业/策略目录，能看到标题、作者、日期；全文可能需登录，覆盖包含非A股。
- 高盛：2024-11-18发布的2025展望公开删节版已阅读，学习盈利/估值分解、多指标历史比较、集中度；不沿用过期市场预测。
- J.P. Morgan：2026-07-01公开搜索摘要，直连受限，明确标注未核验全文。

资料只形成短篇原创方法笔记和分析结构，未复制付费书籍或研报全文，也未完成研报语料微调。机构评级和目标价不作为预测标签。引用具体报告须补齐机构、作者、标题、日期、证券、原文链接及页码；事实、机构观点和模型假设分别标注。

# 股票策略验证台

## 4000只以上股票池

`broad_universe.py` 通过新浪按证券代码分页发现当前沪深A股（排除当前ST、退市标记及北交所），按代码去重；列表缓存7天。东方财富仍提供前复权日线和成交量。不再限制2015年前上市，至少400根有效量价日线的证券才纳入，新增公司从各自真实上市日期进入每日等权统计，不补造上市前数据。每期组合的成分数会变化，当前存续池仍有幸存者偏差，历史ST状态未逐日建模。

发现列表及最终模型均要求至少4000只；不足时终止，不把旧版数百只结果当作扩容成功。结果附 `coverage`，区分发现、纳入、排除数量。应用后台每步超时提高到2小时以容纳首次下载和大股票池回测。内存聚合按逐股收益累计求均值，避免构造全股票日期的大型中间表。

## 2026-11-02：来源研究、持续复盘与账户同步

新增5个预先固定规则的研究候选：Z-B1（J=-10/-20）、Z-B2量价确认、常士杉五日量价、波段反弹。来源、核实等级、工程阈值和未实现内容登记于 `src-tauri/resources/strategy/research_sources.json`。Z哥规则依据公开二手学习整理，不能称为作者原版；三低缺历史时点基本面，不倒填数据。3221比例不明确，保留原账户参考实现。当前股票池存在幸存者偏差，模拟未覆盖逐日ST、最小佣金和整数手约束。

`refresh_research.py` 使用既有固定股票池更新真实OHLC及成交量；量价共同有效且至少400日才纳入同一比较池，至少500只才发布模型。选优仅使用2022年前训练和2022—2023验证，2024后仅作历史样本外评价。新规则发布前的历史回测仍有研究者选择偏差，不能当成真实前瞻业绩。基线页面保留原日期，更新模型独立标注其数据日期。

应用运行时，默认工作日北京时间16点后每日尝试一次复盘（节假日由行情日期体现）；可在策略页关闭，关闭应用期间不运行。失败保留旧快照，可手工重试；自动错误保存在 `strategy.auto.error` 本地缓存。运行脚本、真实缓存与预测账本均保存在应用数据目录，不修改原D盘项目。

预测账本保存首次发布概率，以后只有预测开盘间隔全部实现才结算，不覆盖旧概率。同周期累计20条已结算记录后，用最近100条均值误差作最多±10个百分点的概率偏差修正；这是有限校准，不保证改善。历史走势验证改为按horizon+1间隔取样以减少重叠。当前5/20日预测仍覆盖原研究持仓两只，其他股票同步的是策略信号，不伪造逐股预测。

股票账户直接读取同一成功快照，按证券代码匹配，所有账户都会显示模型同步建议；计划AI上下文附带同一信号、预测和验证门槛。无覆盖、超过7日、未来日期或任一样本外门槛失败时显示观望。模型独立暴露不换算为账户股数，人工计划、可卖量和预算仍需核对，不改变持仓或真实成交。

股票模块顶部的「策略验证」接入了 `D:\strategy` 的策略平台。保留策略概览、样本外回测及净值/回撤曲线、候选策略比较、个股筛选、持仓预测和训练验证结果。点击个股表的代码返回行情看板；「筛选当前股票」使用看板选中的证券代码。

这是源码和结果的集成快照，不依赖原项目目录，也不启动本地 HTTP 服务。HTML 在仅允许脚本的 iframe 沙箱中运行，结果通过内嵌 JSON 提供，不能访问 Tauri 权限。原项目持仓是固定的研究样本，尚未与 GoldEarth 股票账户持仓同步。

## 更新并复盘

桌面应用调用内置的 `build_platform.py`，成功后调用 `strategy_lab.py`。需要本机 Python 3.10+、numpy 和 pandas：

```powershell
python -m pip install -r src-tauri/resources/strategy/requirements.txt
```

默认使用 PATH 中的 `python`；启动应用前可设置 `GOLDEARTH_PYTHON` 为解释器绝对路径。脚本源码编译进桌面程序，无需单独分发 Python 脚本。查看内置结果不需要 Python；普通浏览器预览不提供执行入口。

运行目录为 Tauri 应用数据目录下的 `strategy`。下载的行情位于 `data`，两份原始结果和复盘历史位于 `platform`，应用读取最后一次成功发布的 `snapshot.json`。两个步骤都成功且结果校验通过才发布快照；失败、超时不替换旧快照。每步超时 30 分钟，同一应用进程只允许一次复盘。首次运行会下载股票池历史数据，原项目约 94 MB 的缓存不随应用打包。复盘历史由原引擎按数据日期去重保存，没有自动创建定时任务。

结果页会显示行情截至日期和生成时间；数据源返回旧行情时不会将其改写为今天。持仓、股票池及回测规则保持原项目定义。
